# За буквами на рынок

Игра: https://plairpro.github.io/market/

34 ряда букв, 3 жизни, сбор овощей и фруктов в любом порядке. Управление: стрелки, A/D или касания по сторонам экрана.

Разработано на основе plairpro/rover. Модель Московского рынка выполнена по предоставленным фото, логотип — kznmarket.ru.
